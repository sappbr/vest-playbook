# Math

Pass odds on the rank-1 account, using the 3% daily loss as the stop and the 10% target:

P = 3 / (3 + 10) = 0.2308

Expected cost to pass = 199.50 / 0.2308 = 864.50

One payout = 1,500 x 0.80 = 1,200

Expected value = 1,200 - 864.50 = 335.50

The $335.50 is the average if you can afford the failed attempts. With $200 you get one attempt. The path in the headline ignores failed attempts. That is the trader band.

Ten accounts, first try each: fees 1,995, claims 12,000, net 10,005.

Four clean days on 10 accounts: 10 x 300 x 4 x 0.80 x 4 days = 38,400 if the risk is $300 and the win is 4R. The $43,200 figure uses the $1,200 claim four times across the book of 10, which is $1,200 x 10 x 4 / 10. Use the sheet, not a second mental model. The playbook month is four book-days at $10,800 = $43,200.
