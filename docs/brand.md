# Brand

The page shape follows Vest: short pages, a table near the top, numbered steps, one hint under each rule. The accent is not green.

Set this in GitBook after sync. Customization, Custom theme, dark mode on.

| Token | Hex | Use |
|---|---|---|
| Background | `#121418` | Page |
| Surface | `#1C2128` | Cards |
| Text | `#F2F4F7` | Body |
| Muted | `#A8B0BA` | Secondary |
| Accent | `#E8A838` | Links, buttons, hints |

Amber on that background is about 10:1. Green is Vest's. Do not use it.

{% hint style="info" %}
GitBook does not read these colors from the repo. Set them in Customization, then check dark mode.
{% endhint %}
