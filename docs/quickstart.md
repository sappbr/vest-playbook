# Quickstart

You need $200, a Vest account, and the code GUS. If the fee is not $199.50, stop.

1. Buy Platinum, 1-step, 10% target, 3% daily loss, 80% split.
2. Trade NQ, 09:30 to 11:30 ET, one position, stop inside $750, flat 16:00.
3. Hit $2,500. The funded account is live. No activation fee.
4. Claim at $1,500 gross. Wait 24 hours. You receive $1,200.
5. Keep $798. Buy the next account with the rest.

One fail on the first account ends the $200 path. The $53,205 figure assumes every pass lands on the first try.
